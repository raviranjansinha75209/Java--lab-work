# Bank Account Management System

A beginner-friendly Java OOP assignment demonstrating classes, objects,
a parameterized constructor, and methods.

## Files
- `BankAccount.java` — stores account details and implements deposit,
  withdrawal, balance checking, and detail display.
- `Main.java` — creates two independent bank accounts and tests the methods.

## Requirements
- Java JDK installed
- Terminal or an IDE such as VS Code

## Compile and run
Open a terminal in this folder and run:

```bash
javac BankAccount.java Main.java
java Main
```

## Expected final balances
- Ravi (Account 101): Rs. 5500.0
- Aman (Account 102): Rs. 11000.0
